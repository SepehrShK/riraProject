# Currency Converter

🔗 [مشاهده سایت](https://sepehrshk.github.io/riraProject/)

## قابلیت ها

* تبدیل ریال به دلار
* تبدیل دلار به ریال
* دریافت قیمت به صورت زنده
* به روزرسانی قیمت دلار به صورت خودکار پس از 5 دقیقه
* Responsive

## API

قیمت دلار از سرویس تیندکس دریافت میشود و در localStorage ذخیره میشود
این قیمت به صورت خودکار پس از 5 دقیقه آپدیت میشود
این تایمر 5 دقیقه ای با رفرش سایت 0 نمیشود و فقط وقتی از آخرین باری که قیمت آپدیت شده 5 دقیقه گذشته باشد، آپدیت میشود

## API Token

مقدار واقعی توکن در .env قرار میگیرد
مقدار توکن برابر است با
VITE_API_TOKEN = "YOUR_API_TOKEN"
میتوانید در آدرس https://tindex.app/ توکن حود را دریافت کنید
